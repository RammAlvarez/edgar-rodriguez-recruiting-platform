Fix in the run:

- **D-031** `PlatformDbContext.ConfigureConventions`: a date-time sent with an offset other than Z (`2026-10-19T10:00:00-06:00`)
  reached Npgsql, which only writes offset 0, and the API answered 500 «Ocurrió un error inesperado». Every `DateTimeOffset` is now
  stored as the same instant in UTC (a first version, a JSON converter, dropped `null` from the nullable timestamps in the OpenAPI
  types; the regenerated types showed it and it was replaced). The screens always send `toISOString()` (Z), so only
  other API clients could hit it. `CandidateTests.A_date_time_with_an_offset_is_stored_as_the_same_instant` fails without it.
